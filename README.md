# Sistematización de Métodos Estadísticos 
## Descripción del proyecto 
Repositorio destinado a la documentación del proceso de análisis de datos mediante métodos estadísticos, utilizando documentos reproducibles. 
## Objetivo general 
Sistematizar los procedimientos de análisis estadístico para facilitar la interpretación, organización y reproducción de los resultados. 
## Objetivos específicos 
-	Organizar y preparar bases de datos. 
-	Aplicar métodos estadísticos descriptivos e inferenciales. 
-	Elaborar tablas y gráficos estadísticos. 
-	Interpretar los resultados obtenidos. 
-	Documentar los procedimientos de análisis. 
## Metodología 
1.	Recolección de datos. 
2.	Limpieza y preparación de datos. 
3.	Análisis estadístico descriptivo. 
4.	Análisis estadístico inferencial. 
5.	Visualización de resultados. 
6.	Interpretación y conclusiones. ## Estado del proyecto En desarrollo.
